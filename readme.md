# Jeu de Memory en Python

Petit projet Python réalisé en fin de terminale
Il s'agit d'un jeu de memory basique

Il implémente :
- Le positionnement aléatoire des tuiles au début de la partie
- Un délai avant de recacher les cartes
- Le maintien à découvert des cartes trouvées

## Prérequis sous Linux :
```bash
sudo apt install python3-tk
```

## Lancer le jeu
python3 memory.py
